# exercice-github-vscode
je m'exerce à interagir avec le vscode de ma chromebook 

Voici comment procéder dans Visual Studio Code : 

0. git clone <url>          (une seule fois)
1. cd projet                (ou ouvre directement ce dossier dans VS Code)
2. git pull                 (on récupère la dernière version) 
3. git status               (vérifie l'état du projet) 
4. je code
5. git status               (Git te dit précisément quels fichiers sont concernés) 
6. git add fichier1.py fichier2.py
7. git status
8. git commit -m "message indiquant les modifications"
9. git push

Autre option de clonage : 
| Action                      | Commande                      |
| --------------------------- | ----------------------------- |
| Aller dans le dossier cible | `cd ~/main/ojete`             |
| Cloner                      | `git clone <url>`             |
| Changer le nom du dossier   | `git clone <url> nouveau_nom` |
